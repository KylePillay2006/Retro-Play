Design a modern gaming website called RETRO//PLAY.

IMPORTANT:

This website is built and maintained by a SINGLE DEVELOPER.

Keep the design SIMPLE, CLEAN, PRACTICAL and EASY TO IMPLEMENT.

Do NOT over-design it.

Do NOT add unnecessary animations, complicated layouts, excessive decorative elements, 3D effects, particles, complex glassmorphism, or excessive neon.

The goal is:

80% visual impact
20% complexity.

The website should feel polished and modern without requiring a large design system or complicated frontend implementation.

==================================================
DESIGN DIRECTION
==================================================

Theme:

RETRO FUTURE GAMING.

Take inspiration from:
- early 2000s PC gaming
- modern gaming platforms
- minimalist dark UI
- subtle futuristic interfaces

The site should feel nostalgic but NOT look outdated.

Think:

"Modern gaming archive with a retro personality."

==================================================

Dark background.

1px subtle border.

image scale: 1.03

border changes to subtle green.

Keep animation around 150–250ms.

No 3D tilt.

No particle effects.

No complicated animations.

==================================================
ANIMATION
==================================================

Use ONLY subtle animations.

Allowed:

- button hover
- card hover
- image zoom
- fade-in on page load
- smooth scrolling
- dropdown transitions

Do NOT use:

- 3D card tilt
- particle systems
- animated grids
- complex page transitions
- excessive parallax
- spinning UI
- animated backgrounds
- excessive glowing effects

The site should still feel responsive and polished.

==================================================
FINAL DESIGN GOAL
==================================================

The final website should be:

MODERN
CLEAN
FAST
NOSTALGIC
EASY TO USE
EASY TO DEVELOP

It should NOT look like a giant gaming portal.

It should feel like a small, carefully designed indie project.

Less fluff.
More games.

The user should be able to:

1. Open the website.
2. Search for a game.
3. Filter games.
4. Open a game.
5. Understand the game immediately.
6. Find the legitimate download/source button.

Everything else is secondary.

Prioritize usability and visual polish over decorative features.
