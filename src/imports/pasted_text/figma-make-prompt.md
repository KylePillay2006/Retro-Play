 Design the UI as if it will use rich micro-interactions.

 Important interactions:

 1. Game cards tilt subtly toward the cursor.
2. Game artwork gently zooms on hover.
3. Buttons have magnetic hover effects.
4. Neon borders brighten on hover.
5. Sections fade/slide into view during scrolling.
6. Stats count upward when entering the viewport.
7. Hero grid slowly moves toward the viewer.
8. Background gradient blobs move very slowly.
9. Search results animate smoothly when filtering.
10. Random Game button cycles through game cards before revealing the result.
11. Clicking a game card transitions the artwork into the game-detail hero.
12. Screenshot gallery opens with a smooth fullscreen transition.
13. Buttons have subtle soundless arcade-style visual feedback.
14. Navigation has a small glowing active indicator.

 Keep animations smooth and premium.

 Avoid excessive motion that could make the interface difficult to use.
